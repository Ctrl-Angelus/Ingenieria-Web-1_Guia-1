Backend con Java y Spring-boot

¿Qué es el Backend?

Es la parte de una aplicación que se ejecuta en el servidor. Recibe peticiones del cliente (navegador, app móvil), aplica la lógica de negocio, accede a la base de datos y devuelve una respuesta.

Java en el Backend

Java es un lenguaje tipado, orientado a objetos y multiplataforma gracias a la JVM (Java Virtual Machine). Se usa mucho en el backend por su estabilidad, su ecosistema y su rendimiento. Spring Boot requiere Java 17 o superior en sus versiones actuales.

¿Qué es Spring-Boot?

Principalmente, Spring Framework es un framework que facilita construir aplicaciones Java. Su núcleo es la inversión de control y la inyección de dependencias, mientras que Spring Boot es capa sobre Spring que elimina gran parte de la configuración manual. Ofrece autoconfiguración, un servidor embebido (Tomcat) y dependencias agrupadas en “starters”.

Conceptos

Inversión de control (IoC)
el framework crea y gestiona los objetos en lugar de que lo haga el desarrollador con new
Inyección de dependencias (DI)
el framework entrega a una clase los objetos que necesita.
Bean
es un objeto gestionado por el contenedor de Spring
Starter
dependencia que agrupa todo lo necesario para una funcionalidad (por ejemplo, spring-boot-starter-web).
Maven/Gradle
herramientas que gestionan dependencias y la construcción del proyecto.
API REST
estilo de arquitectura para comunicar sistemas usando HTTP.
